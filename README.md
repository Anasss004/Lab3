Lab 3 - Persistance JPA, Cascades et Relations

Projet de gestion des réservations de salles, utilisateurs et équipements utilisant JPA, Hibernate et la base de données H2 en mémoire.

Structure du projet

- com.example.model : Entités JPA (Utilisateur, Salle, Reservation, Equipement).
- com.example : Classe principale (App) pour tester l'exécution et les cascades.

Exécution de l'application et des tests

mvn test
